# 二维码中心测距

扫描建图的地图视图、导航地图工具栏都提供“中心测距”。至少两个定位组时可用；从扫描实时画面点击此按钮会切换到地图。

点击两个定位组，或选择测距起点、终点。地图连接两块二维码板的中心，并显示米制距离；上方同时显示米和厘米。第三次点击地图定位组会开始新一组测距。“清除测距”重置端点；切换地图或页面清除旧选择。

距离为地图平面坐标的直线距离 `sqrt((x2-x1)^2+(y2-y1)^2)`，不包含路径长度、高差或二维码边缘尺寸。缩放和平移不影响数值。多码板按整组中心计算，地图坐标变化会自动更新距离。

草稿地图会明确显示“地图计算值，尚未实测验收”，页面测距可与卷尺结果比较，但不能替代独立实测验收。测距不修改地图、任务或底盘控制。
