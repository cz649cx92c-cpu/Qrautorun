# 标定后的视觉接入

已通过的 `config/camera_calibration.json` 由共享摄像头节点热加载，无需重新采集或重新计算。当前成功结果为1280×720、拟合0.2137px、独立验证最大0.2415px；这些像素误差不能替代实际导航位置精度验收。

导航检测器仅使用已登记地面多码定位组的尺寸、成员ID和几何布局共同计算相对车体的位姿。专用6×6标定板的ID可能与导航组重号，不能直接按导航组尺寸解释。

普通导航检测无结果时，每秒最多执行一次专用标定板几何诊断。诊断匹配当前成功内参中的AprilGrid规格后提示“画面疑似标定板，请换成已登记的地面定位组”。该诊断不返回导航位姿，不参与PnP观测、扫描记录或地图更新。其他情况明确提示未见定位组、未登记ID、几何校验失败、采集时间/局部融合未就绪；扫描页面设备状态下方显示当前原因。

成功内参和安装参数只能使相机具备米制相对位姿计算条件。正式扫描继续要求经过确认的拍摄时间和同期局部轮式/IMU位姿。`capture_timestamp_verified`、轮式倍率与轮角符号尚未实测，不将临时融合位姿伪装成已验证位置；相机标定不会自动解除这些条件或允许实体运动。
