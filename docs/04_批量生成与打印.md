# 温室AprilTag批量生成与打印

打开 `http://192.168.110.98:3080`，左侧点击 **批量打印**。无需启动摄像头或底盘。

- **当前地图全部标记**：打印当前编辑内容中的全部标记，保留每个ID、黑边尺寸和安装坐标。完整打印包包含当次地图JSON快照、铺设图、清单和每张SVG。
- **按编号批量生成**：设置起始ID、结束ID及黑边尺寸。编号范围为0–586，点击“生成全部587个编号”即可生成整个tag36h11码族；此模式不编造地面坐标，适合先铺码后现场采集。
- **生成并打开打印**：新窗口打开整份PDF，在PDF工具栏点击打印并选择全部页面。如果浏览器阻止新窗口，使用下载按钮打开文件。
- **下载整份PDF**：所有编号已排在一个PDF中，不需要逐个打开。
- **下载完整打印包**：ZIP中包含整份PDF、每个ID的SVG、CSV编号清单及中文打印说明。

默认80mm黑边，白色静区后图案占100mm；A4自动2列×2行，全部587张共147页，最后一页3张。地图中的混合尺寸按最大图案计算排版，保证尺寸不被缩放。

## 已生成文件

`prints/apriltags-Q000-Q586-80mm-packed.pdf` 和同名ZIP。可直接打开 `http://192.168.110.98:3080/api/print/all.pdf` 获取全部标记PDF。

## 打印设置

选择A4、单面、全部页面、100% / 实际大小。关闭适应页面、缩小页面和打印机额外的多页合一。PDF已排版，不要再设置每张纸打印4页。

先印一页，用尺检查50mm标尺以及80mm黑色外边界，正确后再整批打印。保留完整白色静区，编号在静区之外。安装+X是印纸上的向右箭头；按地图安装角度铺设。

## 命令行生成

```bash
cd /home/orangepi/ugv/QRautorun/qr_navigation_ws
# 全部587张，80mm黑边，A4自动排版
node --import tsx scripts/generate_batch_print.ts
# 指定编号和尺寸
node --import tsx scripts/generate_batch_print.ts --start 0 --end 99 --size-mm 80
# 打印已导出的地图；保留地图中每张的ID和尺寸
node --import tsx scripts/generate_batch_print.ts --map maps/greenhouse-example.json
# 每页一张
node --import tsx scripts/generate_batch_print.ts --start 0 --end 29 --layout single
```
