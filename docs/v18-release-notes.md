# v18 — 连续倒车过码与可信二维码锚点纠偏

日期：2026-11-09。此版本保存当前现场版本，作为后续控制平顺性与融合质量改进前的基线。

## 新增与修复

- 同向、方向与航向连续的 4T4D 倒车支持连续过码，不再在每个中间二维码处强制停车。
- 前后换向、横移切换、转弯、终点及安全异常的停车保护保持。
- 可信二维码校正接受后，同周期重算横向参考，并用于前进/倒车 lookahead 纠偏。
- 锚点模式采用 0.35 m lookahead、最多 6°回归航向参考；原有角速度、曲率和变化率限制仍生效。
- 连续换段保留指令速度、转向变化率状态及可信 DR 锚点；避免同一反馈周期重复积分。
- 增加锚点 sigma 校验；原始、错误作用域或失效观测不能启用可信锚点控制路径。
- 运行取证增加 steeringSource 与 anchorLookaheadM 字段。
- 新增倒车连续性与二维码锚点纠偏测试，更新旧预算测试语义。
- 包含本地尚未推送的静止定位协方差标定提交 fcac739。
