# 一次示教扫描后导航

2026-10-13。网页现在只保留“扫描建图”和“开始导航”。原底盘、CAN协议和手柄工程没有修改。

## 使用流程

1. 将不同ID的AprilTag铺设在温室地面。标记尺寸需与摄像头参数及页面“已打印黑边尺寸”一致，默认对应此前打印的80mm标记；每个标记必须有唯一ID。
2. 打开 `http://192.168.110.98:3080`。点击“开始扫描”，用原手柄遥控小车走一遍实际作业流程：行外停靠点出发 → 前进入行 → 原路倒车退出 → 行外横移 → 下一行。车体始终保持朝向，扫描至少3个不同编号。
3. 每行从行外停靠点到作物行入口的实际距离需一致，在“铺设参数与坐标校准”设置。默认0.8m是待核对参数，不能当作现场测量。通道净宽默认0.6m。
4. 点击“完成扫描并生成地图”，系统先保存记录，再优化重复观测、生成地图草稿和前进/倒车/横移任务。所有结果使用真实观测，首次页面不显示示例地图或虚拟车辆。
5. “开始导航”页面选择扫描地图，完成至少3个地面标记的现场坐标确认，最大基线至少1m、坐标差不超过3cm。扫描优化残差是内部观测一致性，不能用来替代真实位置误差。可在扫描高级设置填写已知基准点后重新整理。
6. 原底盘独占、手柄接管、实际IMU、轮角/轮速标定、实时融合定位及摄像头等条件均通过后，才能请求导航。扫描起步停靠点就是第一行导航起点。

不需要先设计地图、逐张配置动作或重新编号。已经打印的PDF/SVG保留在prints目录，原打印下载接口也保留；打印不再作为网页主功能。

## 实现与限制

- `web/frontend/src/App.vue`：重写为两步操作界面，空白初始画布、真实扫描轨迹/重复ID统计、历史扫描继续补扫、自动整理与任务创建、现场坐标确认、原ROS2安全条件显示。
- `web/backend/src/scan-map.ts`：根据优化后位姿和车体朝向区分前进、倒车、横移；只把前进段生成作物行，往返中心线一致；按路线距离分配标记类型和所属行，不按编号大小猜测顺序。
- 不会把扫描期间的倒车或横移路径当作前进路线。当前支持直行作物行、同朝向横移衔接；复杂曲线、180°掉头和无法衔接的轨迹会被拒绝，需要另外扩展规划器。
- 优化输出的标记角度已经是度，不会再次乘180/π。任务中每个定位规则绑定真实任务ID。
- 生成地图永远是draft，没有自动插入验收证据；低扫描残差不会打开实体导航。候选换行区由示教退出位置估计，车辆尺寸与换行区仍需现场确认。
- 原始扫描最多保存10000组，优化选最多500组，保留首末观测、各标记首末出现和运动方向改变处，再均匀抽样。超出复杂度会提示分段扫描，原始数据仍保存。
- 停止后才能整理；补扫新增观测会清除旧优化结果，避免使用过期结果；同一次扫描重复生成不会覆盖原地图。
- 摄像头未标定或局部里程计未同步时不会生成有效扫描记录。默认实体执行关闭，没有自动避障能力。
