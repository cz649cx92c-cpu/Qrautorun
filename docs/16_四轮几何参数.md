# 四轮几何参数

2026-10-14用户提供轴距350毫米、轮距250毫米，已写入 `config/wheel_odometry.yaml`。按前后轴、左右轮对称布置，以四轮轮心矩形中点作为车体平面原点，X向前、Y向左。

| 轮子 | X / 米 | Y / 米 |
|---|---:|---:|
| 左前 LF | 0.175 | 0.125 |
| 右前 RF | 0.175 | -0.125 |
| 左后 LR | -0.175 | 0.125 |
| 右后 RR | -0.175 | -0.125 |

轴距不是车身总长，轮距不是车身最大宽度，因此未用这两个数字修改地图中的车体碰撞包络或相机安装参数。原底盘工程未修改。

本次只配置几何；轮速方向、转角方向与零点、四轮反馈时效仍需原手柄低速实测。`calibration_verified`、`field_freshness_verified`、实体执行许可保持关闭，填写尺寸不代表已经完成运动标定，也不会触发实际运动。
