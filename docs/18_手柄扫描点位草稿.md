# 手柄扫描点位草稿

2026-10-14已接通独立只读草稿采集。网页“扫描建图”可用原遥控器沿直行作物行前进、倒车，保存实际定位组观测和点位草稿。相机内参、安装参数须有效；当前使用既有底盘前后速度与Odin仅IMU，经robot_localization输出临时局部位姿。

当前草稿没有完成拍摄时间验证，也没有完成四轮转向、横移和噪声实测。它不能用于实体自主导航。横移模式会使当前临时融合轨迹失效，需要完成四轮验证后接入，不能用旧里程计的vy=0继续积累横移轨迹。

## 操作

1. 打开 `http://192.168.101.212:3080/`，刷新网页。
2. 新建扫描，保持摄像头和IMU安装不变，用原遥控器低速经过已登记的不同定位组。
3. 通过“地图 / 实时画面”查看点位和画面，识别次数与草稿帧数实时累计。
4. 使用“保存点位草稿”结束扫描并保存。一个定位组也可保存未完成地图；该草稿没有自动生成作物行或安全换行区。
5. 要生成完整路线，仍需至少3个定位组及足够长、符合通道条件的示教轨迹。草稿采集形成的地图保持未验证状态，正式地图需在传感器和坐标验证后重新采集。

同一次局部定位原点下可继续补扫。融合重启、时间回退或数据断流后，不允许把新原点混入旧扫描。旧扫描继续保留，重新建一条扫描记录。无导航任务引用的点位草稿可与扫描记录一起通过删除确认删除；已有导航地图保持原保护。

## 数据边界

草稿节点只订阅 `/qr/odometry/provisional`、`/qr/fusion/status`、`/qr/camera/status` 和 `/qr/tags/provisional`，仅发布 `/qr/tags/draft_observations`、`/qr/draft/status`。接收时戳与局部位姿进行插值，但保留 `synchronized:false`、`timestampSource:server_receive`、`quality:draft` 与定位原点 `localEpoch`。

Web桥只把草稿写入扫描队列，不更新正式导航位姿、二维码动作触发或正式相机条件。后端检查打印布局、观测成员与原点一致性；地图保存 `captureQuality:draft`，坐标验收和导航启动均拒绝此类地图。

遥控器实测停车反馈档位为0，因此仅在全部反馈速度为零、IMU稳定且不处于横移模式时，允许启动静止校零。原CAN协议、控制定义和原底盘工程没有修改。
