# v4 软件改动与运行边界

路径编辑的“属性”中可查看地图原二维码。点选地图码后点“预览所选码”，或从“查看地图二维码”选择：单码显示原 tag36h11 ID 和黑边尺寸；定位板显示原板编号、整板尺寸和所有真实子码，可分别下载原尺寸整板或单码 PDF。预览与补打接口只读原地图版本和登记表，不登记新码、不改编号、不改地图。尺寸缺失明确禁止推测补打；原板与登记冲突仍返回 409。

子码补打保留实际尺寸，包括 100 mm 的 4×4 板上 18.8 mm 黑边子码。A4 无法容纳的原尺寸拒绝缩放。整板沿用每组中央白缝唯一 8 mm 十字、0.15 mm 线宽及安全省略策略，PDF 保留 100% / ACTUAL SIZE 和 50 mm 校验尺。

码间运动策略按有向区间与重复次数保存，支持自动、保持朝向前进/倒车、保持朝向左/右平移和转向后前进。属性显示起始朝向、转角/方向、行进方向和到达朝向；地图蓝箭头表示行进、琥珀箭头表示车头。保存、加载、另存、任务不可变快照及 409 草稿保护保留，旧路线默认自动。新策略不改变底层地图几何与验收链。
