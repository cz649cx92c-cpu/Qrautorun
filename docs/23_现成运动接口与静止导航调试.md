# 现成运动接口与静止导航调试

二维码导航复用 `/home/orangepi/ugv/autorunlida` 使用的
`/home/orangepi/ugv/control/fw_mini_controller.py`，不修改现成运动模块。
`motion_interface.py` 仅把二维码导航输出交给 `BodyCommand` / `SteeringCommand`。
速度为 m/s，车体角速度为 rad/s，由现有兼容桥转换成底盘协议 deg/s。
前进和倒车保留速度正负号；横移使用现有 crab 的车体速度接口。
停稳切换轮角使用现有转向接口，移动时不同时发送竞争的轮速命令。

当前按用户要求保持静止调试，实体执行关闭。仅重启本项目的网页、
导航桥、局部融合和草稿采集服务，没有重启现成运动工程。
只读模式不加载 `FWMiniController`，不创建底盘发布者，不发运动、解锁、停车指令。
其它进程已经有控制发布者时拒绝创建第二个控制桥；加载后持续核对端点身份、
人工接管和导航条件。暂停、故障或退出的零速处理不会发轮角对齐命令。
首次控制接口加载只准备接口、不发送指令；等待最多 3 秒完成发现，
重新检查全部门禁后才启动任务。停止或暂停指令取消等待，禁止延迟自动恢复。
每次车体和转向发送前分别核对实时控制权及人工接管，防止两次发送之间的条件变化。
