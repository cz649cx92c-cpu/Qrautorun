# 一米手柄实测

本工程使用ROS2自带rosbag2记录原底盘与IMU，记录器只订阅，不发送运动、解锁或转向命令。

首次正式测试会话：`logs/motion-tests/20261014-141204-10a16ab9/`。`test.json`记录计划距离1米，实际距离保持空值，待用户完成后填写。`active.json`指向当前会话。用户级服务 `qr-distance-test` 保持记录，最长30分钟，停止时发送SIGINT以保存rosbag元数据。

## 实测步骤

1. 在空地标出相距1米的起点和终点。选择车身同一个固定参考点进行起止对齐。
2. 确认记录已经开启，再用原手柄选择正常前进模式，低速直行到终点。
3. 停车后报告实际距离、是否转弯，以及已完成停车；第一轮只测前进，不倒车或横移。
4. 停止记录并比较原里程计、四轮速度积分和IMU。计划距离不能自动当作实测结果；不据此自动打开正式建图或实体执行许可。

记录包括 `/chassis_info_fb`、`/odom`、`/odin1/imu` 和相关传感器状态；原控制Topic仅作订阅审计。未记录激光雷达、Odin视觉或图像视频。
