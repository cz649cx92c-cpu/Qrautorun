# 扫描记录管理

打开“扫描建图”，点击“已保存扫描”下面的记录入口。

- 输入名称、记录编号或时间进行搜索。
- 每条记录显示创建时间、短编号、定位组数和同步观测帧数。同名记录保留独立编号。
- 点击“打开”加载记录；当前记录显示选中状态。
- 点击垃圾桶，再点击“确认删除”。删除扫描记录和其全部观测数据，不影响其他扫描、定位板或地图。
- 正在采集的记录，以及已经生成导航地图的原始记录显示锁定图标，后端也禁止删除。
- 删除当前记录后，清空扫描预览；刷新页面后不会恢复已删除记录。

组件使用已安装的开源 [Reka UI Dialog](https://www.reka-ui.com/docs/components/dialog)，支持键盘 Tab、Esc、焦点管理。界面保留较大字体，兼容平板和手机。

接口：`GET /api/surveys` 返回摘要统计及可删除状态；`DELETE /api/surveys/:id` 删除记录。不存在返回404，采集中或地图引用返回409。数据库删除在同一事务内执行，并记录操作日志。
